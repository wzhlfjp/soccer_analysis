# Junk or No Junk

A beginner-friendly Next.js + TailwindCSS app where users type a food name and quickly see whether it is likely junk food.

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000).
